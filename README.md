TFT Coach Version 1.0

Personal project exploring the use of AI to strategize in TFT

Instructions
Download the python file and run it in terminal whenever playing, easy-to-use UI that captures a screenshot of your game
every 30 seconds providing tips and recommendations based on your board and other opponents that it keeps track of,
click instant tip to receive a tip whenever using the hotkey! 

TFT Coach draws guides from pro players, metatft, and other online guides to help Gemini understand the game of Teamfight Tactics
and advise possible moves or strategies based on your positioning in the game and what is meta
