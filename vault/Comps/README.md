# Comps — per-comp playbooks

One note per comp you actually play, combining machine-fetched meta data with personal
experience. Created on first play, updated by the post-game reflection.

Frontmatter: `set`, `patch_range`, `tier`, `games_played`, `avg_placement`, `style`
(fast-8 / slow-roll / tempo). Body sections: core board & items, augment priorities,
leveling plan, personal notes (what keeps going wrong/right *for you* on this comp),
linked game notes.

When a set rotates, the folder is archived wholesale — comp knowledge is set-bound by
definition. Evergreen insights get extracted into Lessons first.
